# 智慧路跑 NFC 多場次共用晶片計時平台 v3.0

支援 **建立多場路跑活動**、**同一晶片跨活動重複使用（晶片僅寫入姓名＋身份證字號）**、**事前匯入各活動選手名單與組別**、**選取活動鎖定站點感應比對**、**無網路離線作業＋連網統一上傳同步** 的 PWA 計時系統。

---

## 一、核心運作邏輯（多場次共用晶片）

1. **建立多場活動（後台）**：管理員可在平台建立多場路跑活動（例如「春季城市馬拉松」、「秋季海岸公益路跑」），每場各自擁有獨立的分組、鳴槍時間、感應站點與參賽名單。
2. **事前匯入各活動名單（後台）**：針對每場活動匯入參賽選手明細（`參賽編號,姓名,身份證字號,分組代碼`）；同一位選手可用不同參賽編號與組別報名多場活動。
3. **共用晶片寫入（報到端 `writer01`）**：
   - 晶片內**僅寫入 `姓名|身份證字號`**（約 22 bytes，體積極小、全型號 NTAG 穩定寫入）。
   - 亦支援 **🔗 僅綁定晶片 UID**（適用唯讀卡 / MIFARE 卡）。
   - 選手發卡一次即可重複參加本平台所有活動，免重新寫卡。
4. **依選取活動進行鎖定站點感應（感應端）**：
   - 作業人員登入時選取作業活動（或由帳號鎖定特定活動）＋鎖定指定感應站點。
   - 選手晶片刷過後，系統依晶片內的「身份證字號（或 UID）」**自動比對該場活動的事前匯入明細**，即時帶出該場參賽編號、組別並開始計時；若非該場報名選手立即紅燈攔截，避免跨場誤計。
5. **公開即時查詢（`public.html`）**：民眾免登入，可自由切換各項活動查詢選手動態、最後站點、預估完賽時間 (ETA) 與排行榜（身份證全面隱碼）。

## 二、Google 試算表 6 張工作表（v3.0）

將 `gas/Code.gs` 貼入 Apps Script 並執行 `setupSheets()` 後自動建立：

| 工作表 | 說明 |
|---|---|
| `GlobalConfig` | 最高管理員帳號密碼與公開預設活動 |
| `Events` | 所有路跑活動清單（含各場分組鳴槍與站點設定） |
| `StaffAccounts` | 作業員帳密、作業權限、限定活動與鎖定站點 |
| `Chips` | 跨活動共用晶片主檔（`idNumber`、`name`、`nfcUid`） |
| `Registrations` | 各活動事前匯入的參賽選手明細與組別 |
| `Scans` | 各活動毫秒精準感應紀錄（含 `eventId` 與操作員） |

---

## 三、系統預設測試帳號

- **最高管理員**：`admin` / `admin1234`
- **共用晶片寫入組**：`writer01` / `1111`
- **各站感應組**：`start01`、`cp1`、`cp2`、`cp3`、`finish01`（密碼皆為 `1111`）
