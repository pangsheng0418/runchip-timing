# 智慧路跑 NFC 多場次共用晶片計時平台（v3.6 完整建置與操作手冊）

本系統為免編譯之網頁應用程式（PWA），整合 **Web NFC 晶片讀寫**、**選手報到感應**、**多管理者活動隔離**、**已結束活動鎖定保護**、**本地 IndexedDB 離線計時** 與 **Google 試算表雲端多機同步**。適合馬拉松、公益路跑與超馬繞圈計時賽使用。

---

## 一、系統核心功能總覽

| 核心特色 | 功能說明 |
|---|---|
| **多場次活動＆多管理者隔離** | 同一平台可建立多位主辦／活動管理者帳號；**每位管理者登入後僅檢視與管理「自己建立的活動」與名下作業員**，徹底避免誤改他人活動。 |
| **支援兩種活動性質** | 1. **🏃 一般距離路跑**（如 42K / 21K / 10K，依完賽時間排名，含中途補給站分段配速與 ETA）。<br>2. **🔁 繞圈計時賽**（如 6H / 12H / 24H，無中間管制點，設定每圈公里數如 `2.54 km`，依累積總里程排名）。 |
| **統一律定起跑時間（簡化計時）** | 各活動於後台統一設定「**律定起跑時間**」（支援一鍵統一鳴槍或指定 `HH:mm:ss` 套用全組）；**不設起點感應門，亦不另計個人淨時間**，簡化現場設備與成績顯示。 |
| **選手報到晶片感應 (`CHECKIN`)** | 賽前由報到組 (`checkin01`) 感應選手晶片即時登記到場，掌握「已報到 / 未報到」人數；同時支援一般距離賽與繞圈賽，且**報到感應絕不計入繞圈次數或賽道成績**。 |
| **跨場次共用 NFC 晶片** | 晶片僅寫入「**姓名｜身份證字號**」（約 20 bytes），選手發卡一次即可重複參加不同場次與組別，免重複寫卡。 |
| **三區權限嚴格管制** | 進入首頁即顯示「**公開查詢頁**（免登入）」、「**晶片計時作業**（帳密鎖定活動與站點防誤刷）」、「**後台管理區**（獨立帳密・活動資料隔離）」。 |
| **離線作業＋自動同步** | 有網路時開機自動雙向同步雲端；山區無訊號時可離線登入並感應暫存本機，連網後一鍵統一上傳（亦支援匯出離線 JSON 檔交由總部合併）。 |
| **個資隱碼與報表備份** | 公開查詢頁全面隱碼身份證字號（如 `A123****89`）；後台支援一鍵匯出 Excel（`.xlsx`，含報到狀態與時間）與 JSON 備份還原。 |
| **已結束活動鎖定防修改** | 活動狀態設為「**已結束**」後，自動從所有下拉選單、作業員感應區與後台其他管理分頁隱藏，避免歷史賽事資料遭誤改；僅於活動清單保留並提供「🔓 重新開啟」確認按鈕（公開查詢頁仍維持唯讀查閱）。 |
| **刪除活動連動清理資料庫** | 刪除任一活動時，一併永久清除本機 IndexedDB 與雲端試算表該活動之報名明細（`Registrations`）與感應資料（`Scans`），並自動收縮試算表空白列以減輕資料庫負荷；跨活動共用晶片主檔（`Chips`）不受影響。 |

## 三、第一次使用者：從零開始建置步驟（約 10 分鐘完成）

### 步驟 1：建立 Google 試算表與部署後端 API

1. 登入 Google 雲端硬碟，建立一份全新的 **Google 試算表**（例如命名為「智慧路跑計時資料庫」）。
2. 點選上方選單「**擴充功能**」→「**Apps Script**」。
3. 將編輯器內原有文字清空，把本專案 `gas/Code.gs` 內容**完整複製貼上**並按 Ctrl+S 儲存。
4. 在工具列上方函式下拉選單選擇 **`setupSheets`** → 點擊「**執行**」：
   - 首次執行會跳出 Google 權限審查視窗，請點「**審查權限**」→ 選取您的帳號 → 點「**進階**」→「**前往（不安全）**」→「**允許**」。
   - 執行完成後，試算表會自動建立 **7 張工作表**：`GlobalConfig`、`AdminAccounts`、`Events`、`StaffAccounts`、`Chips`、`Registrations`、`Scans`。
5. 點選右上角「**部署**」→「**新增部署作業**」：
   - 點擊齒輪選類型：**網頁應用程式**
   - 執行身分：**我**
   - 誰可以存取：**所有人 (Anyone)**
   - 點擊「**部署**」。
6. **複製產生的「網頁應用程式網址」**（格式為 `https://script.google.com/macros/s/....../exec`）。

> **舊版升級部署提醒**：若先前已部署過舊版 `Code.gs`，更新程式碼後請點「**部署 → 管理部署作業 → 右上角鉛筆圖示 → 版本選『建立新版本』→ 部署**」（原網址不變）；新版本（API v3.5+）會自動補齊 `AdminAccounts` 工作表與 `ownerAdmin` 欄位，並啟用「刪除活動時自動清除雲端 `Registrations` / `Scans` 明細資料」功能，不會影響原有資料。

---

### 步驟 2：填入共用雲端網址（讓全部手機自動同步！）

1. 用記事本或編輯器打開 `js/config.js`。
2. 將步驟 1 複製的網址貼入 `DEFAULT_GAS_URL` 引號內並存檔：
   ```javascript
   window.APP_CONFIG = {
     DEFAULT_GAS_URL: 'https://script.google.com/macros/s/貼上您的部署網址/exec',
     AUTO_SYNC_ON_START: true
   };
   ```
3. 設定完成後，無論是主辦電腦、報到與各站工作人員手機，還是民眾打開公開查詢頁，**只要有網路一進入頁面就會自動同步同一份 Google 試算表**。

---

### 步驟 3：上傳至 GitHub 並開啟 HTTPS 網站（Web NFC 必備）

> Android Chrome 的 Web NFC API **強制要求 HTTPS 安全連線**，直接雙擊電腦裡的 `index.html` 無法使用實體 NFC。

1. 在 GitHub 建立一個公開（Public）儲存庫（Repository）。
2. 將整個專案資料夾內的檔案（保留 `css/`、`js/` 子資料夾及填好網址的 `js/config.js`）上傳至 `main` 分支。
3. 進入儲存庫上方 **Settings** → 左側 **Pages**：
   - Source 選 **Deploy from a branch**
   - Branch 選 `main`、資料夾選 `/ (root)` → 按 **Save**。
4. 等待約 1～2 分鐘，即可透過專屬 HTTPS 網址開啟：
   - **系統入口大廳**：`https://<您的帳號>.github.io/<儲存庫名稱>/`
   - **公開即時查詢頁**：`https://<您的帳號>.github.io/<儲存庫名稱>/public.html`

## 五、完整賽事操作流程（SOP）

### 階段 1：管理者帳號與活動建置（賽前後台）

1. **建立多位活動管理者（選用）**：
   - 由最高管理員（預設 `admin / admin1234`）登入後台 →「**🏟️ 活動管理與帳密**」→「**👥 平台管理者帳號列表**」。
   - 點擊「**＋ 新增管理者帳號**」建立不同主辦單位或承辦人帳號並儲存同步。
   - **活動隔離機制**：每位管理者登入後，後台只會顯示與操作「**本人帳號建立的活動**」與名下作業員，絕不會看見或誤改他人活動。
2. **建立路跑活動**：
   - 以負責該場賽事的管理者帳號登入，點擊右上角「**＋ 建立新路跑活動**」。
   - 選擇活動性質（表單範例會依性質自動切換）：
     - **🏃 一般距離路跑**：設定活動名稱、日期、地點；建立後於「**🔫 統一開跑與站點**」設定各組距離與中途補給／終點站累計距離（**不需設定起點感應門**）。
     - **🔁 繞圈計時賽**：輸入**每圈設定公里數**（例如 `2.54`），系統自動建立 `6H / 12H / 24H` 三組與單一 `LAP` 感應區。
3. **事前匯入本活動選手名單與組別**：
   - 切換至「**👥 選手名單與組別匯入**」，確認上方「目前管理活動」正確。
   - 準備 Excel（`.xlsx`）或 CSV 檔案，欄位順序固定為 4 欄：
     ```
     參賽編號,姓名,身份證字號,分組代碼
     A001,林志明,A123456789,42K
     U001,林志明,A123456789,12H
     ```
   - 同一位選手（同身份證字號）可用不同參賽編號與組別匯入多場不同活動。
4. **設定作業員帳號與雲端雙向同步**：
   - 於「**👷 作業員帳號管制**」調整本活動各站帳密（報到感應組站點代碼固定為 `CHECKIN`）。
   - 於「**💾 備份匯出與雲端同步**」點「**🔄 一鍵完整雙向同步**」，將活動、名單與帳密同步至雲端。

---

### 階段 2：選手發卡（寫入共用 NFC 晶片，報到發卡組 `writer01`）

> 若選手已持有本平台發放的共用晶片，可**直接跳過本階段**前往階段 3 報到感應！

1. 使用 **Android 手機 Chrome** 進入「**📡 晶片計時作業**」，以 `writer01` 登入。
2. 從右側名單點選「**帶入寫卡**」（或手動輸入**選手姓名**與**身份證字號**）。
3. **兩種製卡模式（依採購的晶片種類選擇）**：
   - **標準可寫入晶片（NTAG213 / 215 / 216）**：
     1. 點擊「**📡 寫入共用 NFC 晶片**」，將晶片緊貼手機背面 NFC 天線並保持靜止 1～2 秒。
     2. 聽到成功音效即寫入 `姓名|身份證字號`；建議移開 1 秒後點擊綠框「**🔍 點此回讀驗證晶片**」核對並記錄硬體 UID。
   - **唯讀晶片 / MIFARE Classic 卡（若寫入顯示 `NotSupportedError`）**：
     1. 改點「**🔗 僅綁定晶片 UID**」，貼近晶片 1 秒即完成免寫入綁定。
4. 可隨時點「**🔍 讀取 / 測試晶片**」檢查任意晶片內容與該選手已報名的所有活動場次。

---

### 階段 3：賽前現場報到感應（報到組 `checkin01`）

1. 工作人員在報到處開啟系統，選取本次活動並以 **`checkin01 / 1111`** 登入（自動鎖定 `CHECKIN` 報到作業，距離賽與繞圈賽皆適用）。
2. 點擊「**📡 啟動極速 NFC 感應**」，選手抵達現場時刷晶片即可完成報到：
   - **首次報到**：綠閃＋提示音，大字體顯示「**✅ 報到成功**」與「**已報到 X / Y 人**」即時進度。
   - **重複刷卡**：黃閃提醒「已完成報到（無須重複感應）」，避免重複紀錄。
   - **未報名攔截**：紅燈警報攔截非本場活動名單的晶片。
   - **晶片未帶／損壞**：可用下方「**⌨️ 手動補感應**」或由後台「選手名單」點擊「**補報到**」手動登記。
3. 主辦方隨時可於後台「**👥 選手名單與組別匯入**」篩選「**✅ 僅看已報到**／**⏳ 僅看未報到**」，精準掌握到場人數。

---

### 階段 4：統一律定起跑時間與賽道感應計時

1. **設定統一律定起跑時間（不需起點感應門）**：
   - 進入後台「**🔫 統一開跑與站點**」→ 上方「**⏱️ 本活動統一律定起跑時間**」卡片：
     - **現場同步鳴槍**：點擊「**🔫 立即統一鳴槍起跑**」，立即鎖定現在時間並套用至全活動所有分組。
     - **事前律定開跑時間**：輸入預定起跑時間（如 `06:30:00`）→ 點擊「**✅ 律定套用至全活動**」。
   - 開跑時間一經設定，系統即以此為全場唯一計時基準，簡化作業且不另計算個人淨時間。
2. **各站手機感應計時（有網即時 / 無網離線皆可）**：
   - 各站人員先在有網處選取本次活動並登入專屬站點帳號（如 `lap01`、`cp1`、`cp2`、`finish01`），系統自動快取最新名單與晶片主檔。
   - 點擊「**📡 啟動極速 NFC 感應**」，建議開啟「**🔊 音效開**」與「**☀️ 強光高對比**」。
   - **防連點保護**：同一選手在防連點冷卻秒數內重複靠近會自動黃閃略過。
   - **無網路離線作業**：無訊號時紀錄安全存於本機 IndexedDB；恢復網路後點擊「**☁️ 統一上傳離線資料**」批次上傳（或點「**💾 匯出離線檔**」傳送 `.json` 給總部合併）。

#### 選手狀態自動流轉規則

| 狀態 | 判定條件 |
|---|---|
| **⏳ 未報到** | 尚未感應 `CHECKIN` 報到晶片，且無任何賽道感應紀錄 |
| **✅ 已報到** | 已完成報到感應，等待到達統一律定起跑時間 |
| **🏃 賽道上** | 已報到且已達統一律定起跑時間，或已通過任一中途站／繞圈感應 |
| **🏁 已完賽** | 通過終點衝線門（距離賽），或已達限時截止且有圈數（繞圈賽） |

---

### 階段 5：成績修正、Excel 匯出與公開即時查詢

1. **後台成績與報到人工修正（「🏆 成績管理與修正」）**：
   - **一般距離賽**：直接點擊任一選手的「**報到時間**」、「**站點時間**」或「**罰時**」，即可補登、修改或刪除並自動重算名次。
   - **繞圈計時賽**：點擊「**報到時間**」可補改報到；點擊右側「**🔁 逐圈明細 / 補刪圈**」可檢視每圈耗時、補登漏圈或刪除誤刷圈。
2. **匯出 Excel 報表（`.xlsx`）**：
   - 提供「**完整報表（主辦留存）**」與「**隱碼報表（對外公告）**」，自動包含**報到狀態、報到時間、統一完賽時間（或累積總里程）、各分組統計與原始感應紀錄**。
3. **公開即時查詢頁（`public.html`）**：
   - 於後台點「**🌐 複製本活動公開查詢連結**」製成 QR Code 張貼於會場，選手與親友免登入即可即時查詢報到人數、選手最新動態、預估完賽時間 (ETA) 與排行榜。

### 階段 6：賽後鎖定（「已結束」）與刪除活動資料庫清理

1. **賽後將活動設為「已結束」（防資料遭修改）**：
   - 賽事完賽並確認成績匯出後，於後台分頁「**🏟️ 活動管理與帳密**」→「**✏️ 編輯目前活動基本資訊**」將狀態改為「**已結束**」並儲存。
   - 設為「已結束」後的自動保護機制：
     - **所有下拉選單隱藏**：大廳選取活動、作業員登入選單、後台「目前管理活動」、晶片寫入篩選與作業員「限定活動」下拉選單皆不再顯示該活動（若無任何進行中／籌備中活動，下拉選單自動隱藏）。
     - **其他管理分頁不顯示資料**：選手名單、成績管理與修正、統一開跑與站點、本場 Excel 匯出皆不會顯示已結束活動資料，並禁止作業員登入或感應。
     - **重新開啟方式**：僅於「**🏟️ 我的路跑活動清單**」保留顯示（標示 `🔒 已結束（已鎖定）`）；如確需補改資料，可點卡片上的「**🔓 重新開啟**」經二次確認改回「進行中」。
     - **公開查詢頁保留查閱**：`public.html` 屬純唯讀查詢介面，賽後仍可供選手查詢成績。
2. **刪除活動連動清理資料庫（減輕資料庫負荷）**：
   - 欲永久移除舊賽事時，於「**🏟️ 我的路跑活動清單**」點擊該活動卡片的「**刪除**」（確認視窗會提示將清除的報名與感應筆數）。
   - 系統會同步執行：
     - **本機 IndexedDB**：清除該活動所有 `registrations` 與 `scans` 明細紀錄；其他裝置下次同步時亦自動清理快取。
     - **雲端 Google 試算表**：移除 `Events` 活動列，並批次刪除 `Registrations`（報名名單）與 `Scans`（感應資料）中該活動所有資料列且自動收縮空白列。
     - **保留共用晶片主檔**：跨活動共用的 `Chips` 晶片主檔（姓名＋身份證＋UID）不會被刪除，選手下次參賽仍可沿用原晶片。

## 六、重要注意事項與常見問題排錯

### 1. 硬體與手機事前設定清單

| 檢查項目 | 注意事項 |
|---|---|
| **支援裝置與瀏覽器** | Web NFC **僅支援 Android 手機之 Google Chrome（v89 以上）**。<br>❌ 不可使用 iPhone (iOS Safari)、電腦瀏覽器，也**不可在 LINE / Facebook 內建瀏覽器中直接開啟**（請選「以 Chrome 開啟」）。 |
| **建議採購 NFC 晶片** | 建議採購 **NTAG213 / NTAG215 / NTAG216** 抗金屬貼紙或矽膠手環（支援標準 NDEF 讀寫）。若使用唯讀卡或 MIFARE 卡，改用「**🔗 僅綁定晶片 UID**」即可。 |
| **Android 系統設定** | 1. 開啟手機「設定 → 連線裝置 → **NFC 開關**」。<br>2. 開啟「**自動設定日期與時間（網路校時）**」，確保各站時間與統一律定起跑時間精準一致。<br>3. 延長螢幕休眠時間並外接行動電源，避免待機中斷 NFC 感應。 |
| **建議加入主畫面** | 在 Chrome 選單點「**加到主畫面**」安裝為 PWA App，避免單手操作誤觸返回鍵。 |
| **防連點秒數調整** | 一般路跑預設 `30 秒`；若為**繞圈計時賽**（例如單圈 2.54 公里），建議於後台將防連點秒數調高至 `60～120 秒`，避免選手在補給桌逗留重複觸發。 |

### 2. 常見異常排錯速查表

| 狀況 / 錯誤訊息 | 原因 | 解決方法 |
|---|---|---|
| 出現 `NotAllowedError` | Chrome 未允許此網站使用 NFC，或手機 NFC 沒開 | 點擊 Chrome 網址列左側圖示 → 權限 → 允許「NFC 裝置」，並確認手機 NFC 已開啟。 |
| 出現 `NotSupportedError` | 晶片為 MIFARE Classic、悠遊卡或唯讀鎖定卡 | 改點「**🔗 僅綁定晶片 UID**」免寫入直接綁定；或更換 NTAG213/215/216 晶片。 |
| 出現 `NetworkError` | 感應時晶片移開太快，或距離背面天線太遠 | 貼緊手機背面 NFC 天線並**保持靜止 1～2 秒**，聽到成功音效後再移開。 |
| 新建的活動管理者無法雲端登入 | Google Apps Script 尚未更新部署至 v3.5+ 版本 | 將最新 `gas/Code.gs` 貼入 Apps Script，點「部署 → 管理部署作業 → 建立新版本 → 部署」。 |
| 刪除活動後雲端試算表仍有舊明細 | 雲端 GAS 仍停留在舊版，尚未啟用連動清理 | 重新貼上新版 `gas/Code.gs`（v3.5+）並建立新版本部署，之後刪除活動或離線補同步皆會自動清理。 |
| 下拉選單或其他分頁找不到某活動 | 該活動狀態已設為「**已結束**」並啟動防修改鎖定 | 此為防呆保護設計；如需重新編輯，請至後台「🏟️ 活動管理與帳密」清單點該活動的「**🔓 重新開啟**」。 |
| 看不到其他管理者建的活動 | 系統已啟用**多管理者活動隔離**保護機制 | 此為正常設計（每位管理者僅管理本人建立的活動）；民眾端請由公開查詢頁檢視所有活動。 |
| 更新 GitHub 後手機畫面仍是舊版 | 瀏覽器 Service Worker 仍保留舊版離線快取 | 在手機 Chrome **連續重新整理 2 次**，或關閉分頁重新開啟即可自動載入最新版。 |
