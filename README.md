# TUR (Taiwan Ultra Runners) 路跑晶片計時平台（v3.12.12 完整建置與操作手冊）

本系統為 **TUR (Taiwan Ultra Runners)** 舉辦路跑與超級馬拉松活動專屬之免編譯網頁應用程式（PWA），整合：

- **Web NFC 共用晶片讀寫與 UID 雙模綁定**
- **選手現場報到感應 (`CHECKIN`) 與統一律定起跑計時**
- **一般距離賽（含分段配速／ETA）與繞圈計時賽（6H / 12H / 24H）**
- **全系統成績與感應時間統一整數秒 `HH:mm:ss`（無小數點）**
- **後台四大專區頂部橫式選單，點選後才展開對應作業項目**（1. ⚙️ 賽事作業專區 ｜ 2. 📦 已結案專區 ｜ 3. 📜 歷年活動成績匯入 ｜ 4. 🗄️ 資料庫專區）
- **歷年活動成績匯入「先預覽審查、確認後才寫入資料庫」防呆機制與 ⚔️ 八百壯士英雄榜**
- **🏅 DUV 國際超馬協會官方格式成績匯出（`.xlsx` / `.csv`，限定已結案活動）**
- **🏅 官方中英對照＆客製化完賽證書製作／列印（限定已結束與歷年活動；PNG / 單張 PDF / 批次多頁 PDF，100% 離線生成）**
- **本機 IndexedDB 離線作業 ＋ Google 試算表雙向雲端同步**

> **介面設計原則**：主入口大廳採用專業運動科技網格舞台風格並維持極簡結構（僅留左上角單一小型 TUR LOGO、無中央大標題、三張純文字發光邊框入口）；作業人員登錄獨立分流並依所選活動動態列出組別與即時進度；後台採雙身分登入（最高管理權責／活動承辦人）搭配頂部橫式專區選單點選展開，並將歷年匯入與資料庫備份還原限定最高管理權責執行以防誤觸。

## 一、系統核心功能與計時規則

| 核心功能 | 詳細規則與說明 |
|---|---|
| **跨場次共用 NFC 晶片** | 晶片僅寫入 `姓名\|身份證字號`（約 20 bytes），不含活動代碼或參賽編號。發卡一次即可重複參加多場不同賽事與組別，感應時依鎖定活動自動比對選手資格。 |
| **一般距離賽 / 繞圈計時賽** | 1. **🏃 一般距離賽**（42K / 50K / 100K 等）：依完賽時間排名，支援中途補給站分段時間、配速與 ETA。<br>2. **🔁 繞圈計時賽**（6H / 12H / 24H）：依單圈公里數（如 `2.54 km`）累積圈數與總里程排名，逾時圈次留存紀錄但不計入正式成績。 |
| **統一整數秒時間格式** | 全系統所有畫面、排行榜、分段明細、個人卡片、官方／客製化證書、Excel 報表、DUV 匯出與雲端表單，**秒數一律採整數 `HH:mm:ss`（不含小數點）**。 |
| **統一律定起跑與現場報到** | 後台統一設定起跑時間（一鍵立即鳴槍或指定 `HH:mm:ss` 套用全組，亦可單組微調）。賽前由報到組（`checkin01`）刷晶片登記 `CHECKIN`，且**報到紀錄絕不計入圈數或賽道成績**。 |
| **多管理者獨立活動隔離** | 支援建立多位活動管理員，每位管理員登入後**僅檢視與操作本人建立之活動、結案匯出、證書與名下作業員**，防止誤改他人賽事。 |
| **已結束活動鎖定與結案專區** | 活動狀態改為「**已結束**」即鎖定防誤改，自動從大廳、作業員登入、專區 1（進行中活動選單）與公開頁「即時賽事」隱藏；並自動開放於後台「**專區 2：📦 已結案專區**（正式 Excel / DUV 匯出、製作證書）」與公開頁「**📜 歷年成績**」、「**🏅 證書列印**」。 |
| **刪除活動連動清理** | 刪除活動時同步永久清除本機與雲端該活動的報名明細（`Registrations`）與感應紀錄（`Scans`）並收縮試算表，共用晶片主檔（`Chips`）保留不受影響。 |
| **歷年匯入審查與 ⚔️ 八百壯士** | 「**專區 3：📜 歷年活動成績匯入專區**」上傳或貼上後**先顯示預覽場次與明細供審查，確認後才寫入資料庫**；凡活動名稱含「**八百壯士**」（進行中、已結束或歷年匯入）自動整合至公開頁「**⚔️ 八百壯士**」當年度整合排名與跨年度英雄榜。 |
| **🏅 DUV 官方成績匯出** | 獨立設於「**專區 2：📦 已結案專區**」（僅列已結束活動），一鍵匯出符合 **DUV (Deutsche Ultramarathon-Vereinigung)** 送審格式（3 列活動表頭＋11 欄明細）之 `.xlsx`（同表堆疊／分組工作表）與 `.csv`（UTF-8 BOM）；自動拆中文姓／名並依台灣身份證第 2 碼推算性別。 |
| **🏅 完賽證書製作與客製化** | • **範圍限定**：後台「**專區 2 → 🏅 製作證書**」與公開頁「**🏅 證書列印**」皆**僅包含「已結束」與「歷年」活動**（進行中與籌備中一律排除）。<br>• **後台製作**：提供「**🏛️ 官方中英文對照公版**（大字活動名、4 格主成績、分段成績、底部並列活動日期／金色鋼印／TUR LOGO，無賽事總監字樣）」與「**🖼️ 上傳自訂底圖拖曳套印**」，100% 離線輸出 PNG、單張 PDF 與**批次多頁合併 PDF**。<br>• **公開列印**：選手免登入下載官方樣式，或使用「**✨ 客製化**」上傳**自訂底圖＋個人照片**（3 款相框、縮放、畫布直接拖曳構圖、感言）下載 PNG／PDF／直接列印。 |
| **離線作業＋資料庫專區** | 山區無訊號可離線登入感應並存於本機 IndexedDB；「**專區 4：🗄️ 資料庫專區**」整合資料庫即時統計、JSON 備份與還原（合併／覆蓋）、Google 試算表雙向同步與全情境測試資料重置。 |
| **個資隱碼保護** | 公開查詢頁與隱碼 Excel 全面隱碼身份證（如 `A123****89`），並隱藏選手出生年月日（`DOB`）；查詢仍支援完整身份證以 SHA-256 雜湊安全比對。 |

### 選手狀態自動流轉規則

| 狀態 | 判定條件 |
|---|---|
| **⏳ 未報到** | 尚未感應 `CHECKIN` 報到晶片，且無任何賽道感應紀錄 |
| **✅ 已報到** | 已完成 `CHECKIN` 報到感應，等待到達統一律定起跑時間 |
| **🏃 賽道上** | 已報到且已達起跑時間，或已通過任一中途站／繞圈感應 |
| **🏁 已完賽** | 距離賽通過終點衝線門（`FINISH`）；繞圈賽達限時截止且有有效圈數 |

## 三、從零開始建置與版本升級步驟（約 10 分鐘完成）

### 步驟 1：建立 Google 試算表與部署後端 API

1. 建立一份新的 **Google 試算表**（例如「TUR 路跑晶片計時資料庫」）。
2. 點選上方「**擴充功能**」→「**Apps Script**」，清空預設內容，將 `gas/Code.gs` 完整貼上並儲存。
3. 上方函式選單選 **`setupSheets`** → 按「**執行**」（首次需授權「進階 → 前往 → 允許」），自動建立 **8 張工作表**：
   - `GlobalConfig`、`AdminAccounts`、`Events`（15 欄）、`StaffAccounts`、`Chips`、`Registrations`（14 欄，含 DUV 欄位）、`Scans`、`HistoryResults`（17 欄）。
4. 點右上角「**部署**」→「**新增部署作業**」：
   - 類型：**網頁應用程式** ｜ 執行身分：**我** ｜ 誰可以存取：**所有人 (Anyone)**
   - 複製產生的部署網址（`https://script.google.com/macros/s/....../exec`）。

> **舊版升級提醒（v3.9 以下升至 v3.10+）**：
> 貼上最新 `gas/Code.gs` 後，請點「**部署 → 管理部署作業 → 鉛筆圖示 → 版本選『建立新版本』→ 部署**」（原網址不變）。既有 `Events` 與 `Registrations` 工作表會自動補齊新增的 DUV 欄位標題，並修正時間格式（去小數秒、防 1899 日期誤判）與重複 ID 匯入問題，不影響舊資料。

### 步驟 2：填入共用雲端網址

開啟 `js/config.js`，將部署網址填入 `DEFAULT_GAS_URL`：
```javascript
window.APP_CONFIG = {
  DEFAULT_GAS_URL: 'https://script.google.com/macros/s/貼上您的部署網址/exec',
  AUTO_SYNC_ON_START: true
};
```

### 步驟 3：上傳至 GitHub 並啟用 HTTPS（Web NFC 必備）

> Android Chrome 的 Web NFC API **強制要求 HTTPS**，直接雙擊本機檔案無法使用實體 NFC。

1. 在 GitHub 建立公開（Public）儲存庫，上傳整個專案（務必保留 `css/`、`js/` 子資料夾，且包含 `js/certificate.js`）。
2. 進入 **Settings → Pages**：Source 選 **Deploy from a branch**、Branch 選 `main`、資料夾選 `/ (root)` → 按 **Save**。
3. 啟用後即可透過 HTTPS 使用：
   - **系統主入口**：`https://<您的帳號>.github.io/<儲存庫名稱>/`
   - **公開查詢頁**：`https://<您的帳號>.github.io/<儲存庫名稱>/public.html`

## 六、完整賽事標準作業流程（SOP）

1. **階段 1（賽前建置 — 專區 1）**：登入管理者 → 建立活動（填妥中文與英文活動名稱）→ 設定分組與站點 → 匯入名單（含選填 DUV 欄位：性別、DOB、城市、國家）→ 設定各站作業員 → 於專區 4 雙向同步並張貼公開查詢 QR Code。
2. **階段 2（選手發卡製卡 `writer01`）**：Android Chrome 登入 `writer01` → 帶入選手 → NTAG 寫入＋回讀驗證（或唯讀卡綁定 UID）；已持共用晶片者免重發。
3. **階段 3（現場報到感應 `checkin01`）**：選取活動登入 `checkin01` → 刷晶片登記報到，未帶卡可手動補登或後台補報到。
4. **階段 4（統一鳴槍與賽道感應）**：專區 1 點擊「🔫 立即鳴槍」→ 各站感應（無訊號離線暫存，連網按「☁️ 上傳」）。
5. **階段 5（賽後核對與正式結案 — 專區 1）**：
   - 於「**🏆 成績**」核對並人工修正異常紀錄（全系統時間統一整數秒 `HH:mm:ss`）。
   - 於「**🏟️ 活動**」將活動狀態改為「**已結束**」即正式結案鎖定防誤改。
6. **階段 6（結案匯出、DUV 送審與證書核發 — 專區 2）**：
   - 於「**專區 2：📦 已結案專區 → 📊 匯出正式 Excel / DUV**」選取已結案活動，下載完整版／隱碼公開版 Excel 與 **🏅 DUV 官方成績檔**（`.xlsx` / `.csv`）送審。
   - 於「**專區 2：📦 已結案專區 → 🏅 製作證書**」批次產製全組 PDF；選手亦可於公開頁「**📜 歷年成績**」與「**🏅 證書列印**」免登入下載官方或客製化個人照片證書。

## 七、Android 硬體事前設定與常見問題排錯

### 1. Android 手機事前設定清單

| 檢查項目 | 注意事項 |
|---|---|
| **支援瀏覽器** | Web NFC **僅支援 Android Google Chrome（v89 以上）**；不支援 iOS Safari、電腦瀏覽器，也**不可在 LINE / FB 內建瀏覽器開啟**。 |
| **建議 NFC 晶片** | 建議 **NTAG213 / 215 / 216** 抗金屬貼紙或手環；唯讀／MIFARE 卡改用「**🔗 綁定 UID**」。 |
| **手機設定** | 開啟 **NFC**、開啟「**自動設定日期與時間（網路校時）**」、延長螢幕休眠並外接行動電源。 |
| **安裝 PWA** | Chrome 選單點「**加到主畫面**」全螢幕運行。 |
| **防連點秒數** | 距離賽建議 `30 秒`；繞圈賽建議 `60～120 秒`。 |

### 2. 常見異常排錯速查表

| 狀況 / 錯誤訊息 | 原因 | 解決方法 |
|---|---|---|
| `NotAllowedError` | Chrome 未允許 NFC 權限或手機 NFC 未開 | 點網址列左側圖示 → 權限 → 允許「NFC 裝置」，並確認手機已開啟 NFC。 |
| `NotSupportedError` | 晶片為 MIFARE Classic 或唯讀卡 | 改點「**🔗 綁定 UID**」直接綁定，或更換 NTAG 晶片。 |
| `NetworkError` | 晶片移開太快或未對準天線 | 貼緊手機背面天線並**靜止 1～2 秒**，聽到成功音效再移開。 |
| 雲端歷年時間變成 1899 年日期或無法寫入 DUV 欄位 | 雲端 GAS 仍停留在舊版（v3.9 以下） | 貼上最新 `gas/Code.gs`（v3.10+）並點「管理部署作業 → 建立新版本 → 部署」。 |
| 專區 1 進行中選單找不到某活動 | 活動狀態已設為「**已結束**」並鎖定 | 至專區 1「**🏟️ 活動**」點該活動之「**🔓 重新開啟**」；若要匯出成績或做證書，請直接於**專區 2（已結案專區）**選取。 |
| 專區 2 匯出或證書看不到進行中活動 | 系統規範僅對「已結束」與「歷年」活動匯出與發證 | 屬正常防呆設計；請先於專區 1「🏟️ 活動」將該賽事狀態改為「**已結束**」結案。 |
| 看不到其他管理員的活動 | 系統啟用**多管理者活動隔離** | 屬正常設計；民眾請由公開查詢頁瀏覽所有活動。 |
| 更新 GitHub 後手機仍是舊版 | Service Worker 尚留舊版離線快取 | 於手機 Chrome **連續重新整理 2 次**即可更新至 `v3.12.12`。 |

## 八、免硬體快速體驗方式（電腦／手機皆可）

1. 開啟 `index.html` → 點金框「**後台管理**」→ 以 `admin / admin1234` 登入（進入後僅呈現精簡的頂部 4 格橫式專區選單）。
2. 點選上方「**🗄️ 資料庫專區**」→ 建議先切「單機離線」→ 展開「**🧪 測試資料與重置**」→ 點「**⚡ 載入全情境測試資料（5 場活動）**」。
3. 依序點選上方橫式四大專區與公開查詢體驗全功能：
   - **專區 1（⚙️ 賽事作業專區）**：切換進行中超馬距離賽（含分段／罰時／外籍與複姓／缺 DOB 提醒）、繞圈賽（含逾時圈與 0 圈報到）與籌備中賽事，檢視無小數秒 `HH:mm:ss` 成績。
   - **專區 2（📦 已結案專區）**：於「🔒 選擇已結案活動」選取 2025 冬季百公里或台北河濱 12H，體驗正式 Excel（完整／隱碼）、**🏅 DUV 官方成績匯出**與「**🏅 製作證書**」（官方中英公版／自訂底圖拖曳／批次 PDF）。
   - **專區 3（📜 歷年活動成績匯入專區）**：展開貼上文字區，體驗「**🔍 預覽審查**」場次彙整、單筆剔除、取消不寫入與確認寫入資料庫。
   - **專區 4（🗄️ 資料庫專區）**：檢視 5 格本機資料庫即時統計，測試 JSON 下載備份與合併還原。
   - **公開頁與選手客製化證書**：開啟 `public.html`，依序瀏覽 **🏃 即時賽事**、**📜 歷年成績**、**⚔️ 八百壯士**，並於 **🏅 證書列印** 體驗官方樣式與「**✨ 客製化（上傳底圖＋個人照片）**」下載 PNG／PDF。
   - **作業人員依活動選組別登入與模擬刷卡**：登出後點綠框「**晶片作業**」→ 切換距離賽或繞圈賽查看動態作業組別與即時進度 → 點選任一組別卡片並輸入密碼登入體驗模擬刷卡。
