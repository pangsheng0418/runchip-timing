# 智慧路跑 NFC 晶片計時系統 v2.0

支援 **三大權限作業區分流**、**作業員帳號鎖定指定感應站點（防選錯站）**、**無網路離線作業＋有網統一上傳同步** 的 PWA 網頁版 NFC 路跑計時系統，免編譯即可直接部署於 GitHub Pages、Vercel 或 Cloudflare Pages。

---

## 一、三大作業區設計（進入系統首頁即顯示）

| 作業區 | 登入權限 | 功能與防呆設計 |
|---|---|---|
| **🌐 公開查詢頁** | 免登入（所有人皆可查詢） | 查詢即時總覽看板、各組進度、選手最後通過站點、預估完賽時間 (ETA) 與排行榜；身份證全面隱碼（如 `A123****89`）。 |
| **📡 晶片計時作業** | 作業員帳號＋密碼 | **依帳號強制鎖定「NFC 晶片寫入區」或「單一指定感應站點」**，無法自行切換站點以防誤感應；無網路時可離線登入與感應，連網後一鍵統一上傳雲端。 |
| **🛡️ 後台管理區** | 最高管理員獨立帳號＋密碼 | 擁有最高權限：建立與修改所有成績、賽事/組別鳴槍/站點設定、管理各站作業員帳密與指派站點、Excel 匯出與完整系統 JSON 備份還原。 |

## 三、Google 試算表 6 張工作表與 GAS 部署步驟

1. 建立一份新的 **Google 試算表** → 點選「**擴充功能**」→「**Apps Script**」。
2. 將 `gas/Code.gs` 內容完整貼入編輯器並儲存。
3. 選擇函式 **`setupSheets`** 並點選「**執行**」，授權後會自動建立 6 張工作表：
   - `Config`（賽事設定與管理員獨立帳密）
   - `Categories`（分組與起跑時間）
   - `Checkpoints`（站點順序與累計距離）
   - `StaffAccounts`（作業員帳密與綁定鎖定站點）
   - `Runners`（選手名單與罰時）
   - `Scans`（晶片感應紀錄與操作員紀錄）
4. 點選右上角「**部署**」→「**新增部署作業**」→ 類型選「**網頁應用程式**」：
   - 執行身分：**我**
   - 誰可以存取：**所有人 (Anyone)**
5. 複製部署網址，登入後台管理區 →「**☁️ 雲端同步與分享連結**」貼入網址並點選「**儲存並測試連線**」。

## 四、山區無網路離線作業與連網統一同步流程

1. **賽前準備（有網路時）**：後台管理員複製「**📡 工作人員端連線網址**」（`index.html?api=<GAS_URL>`）傳給各站手機；各站人員在報到處開啟一次並登入自己的帳號，系統會自動快取該帳號、站點與選手名單至本機 IndexedDB。
2. **賽道無網路作業**：抵達無訊號站點後，作業員仍可離線登入指定站點正常感應計時，所有感應皆安全寫入本機 IndexedDB（畫面顯示「💾 離線暫存」）。
3. **連網後統一上傳**：回到有網路環境時，在作業區上方切換為「**雲端即時連線**」或點擊「**☁️ 統一上傳離線資料**」，所有暫存紀錄會一次批次同步至 Google 試算表並自動防重複。
4. **極端無網備案**：若終場仍無訊號，作業員可點「**💾 匯出離線檔**」匯出 `.json`，交由總部後台點選「**➕ 合併離線備份檔**」彙整所有站點成績。
