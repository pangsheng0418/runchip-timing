# TUR (Taiwan Ultra Runners) 路跑晶片計時平台（v3.13.2 完整建置與操作手冊）

本系統為 **TUR (Taiwan Ultra Runners)** 舉辦路跑與超級馬拉松活動專屬之免編譯網頁應用程式（PWA），整合：

- **主畫面四大圖示化精簡入口（手機一屏完整呈現）**：`📝 活動報名`（連結至 `https://runner2026.vercel.app/`）、`🏆 成績查詢`、`📡 晶片作業`、`🛡️ 後台管理`
- **極速啟動與秒驗登入架構（v3.13 效能升級）**：
  - 首頁與公開成績頁採「**本機 IndexedDB 快取秒開 ＋ 背景非同步雲端更新**」，開啟不卡頓
  - IndexedDB 全面改採「**單一交易批次寫入**」，千筆資料同步僅需數十毫秒
  - 後台登入採「**本機秒驗進入 ＋ 背景雲端複驗**」搭配 GAS `lite` 極速驗證（免搶全域寫入鎖）與公開資料 20 秒短快取
- **最高規格零紀錄帳密防護**：
  - 後台管理登入直接區分「**🛡️ 最高管理權責**」與「**👤 活動承辦人**」，**不顯示快選帳號、密碼永遠預設空白、封鎖瀏覽器自動填入**
  - 管理員登入狀態**僅存於當頁記憶體，絕不寫入 `localStorage`／`sessionStorage`**，防止他人利用登入紀錄進入系統
- **後台五大橫式專區選單（最高管理員 5 欄 ／ 活動承辦人自動隱藏為 3 欄）**：
  1. `⚙️ 賽事作業專區` ｜ 2. `📦 已結案專區` ｜ 3. `👥 帳號管理專區`（最高管理專用） ｜ 4. `📜 歷年活動成績匯入`（最高管理專用） ｜ 5. `🗄️ 資料庫專區`
- **👥 最高管理員統一帳號管理專區**：集中建立與修改 **🛡️ 最高管理員**、**👤 活動承辦人**、**👷 作業人員** 三大身分之帳號、密碼與權限（所有密碼欄預設空白不回填明文）
- **簡化資料庫備份還原 ＋ 單機離線 ⇄ 雲端連線互動指南**：兩步驟完成全機 `.json` 備份與合併／覆蓋還原，並內建 4 步驟離線／連線同步操作指引
- **Web NFC 共用晶片讀寫與 UID 雙模綁定**（模擬感應僅載入本場報名選手）
- **選手現場報到 (`CHECKIN`)、統一律定起跑、一般距離賽與繞圈計時賽（6H / 12H / 24H）**，全系統時間統一整數秒 `HH:mm:ss`
- **⚔️ 八百壯士英雄榜與兩層場次鑽取查詢**
- **🏅 DUV 國際超馬協會官方成績匯出（`.xlsx` / `.csv`）**
- **🏅 官方中英對照證書（6 款格式風格 × 6 款配色主題）＆ 客製化底圖／個人照片證書**（100% 離線輸出 PNG / 單張 PDF / 批次多頁 PDF）

## 一、系統核心功能與計時規則

| 核心功能 | 詳細規則與說明 |
|---|---|
| **秒開架構與極速登入** | 進入首頁與成績查詢頁立即顯示本機快取並於背景同步雲端；IndexedDB 改為單交易批次寫入；管理員登入優先本機秒驗並於背景複驗雲端，GAS 後端 `login` 採 `lite` 免寫入鎖模式、`publicData` 具備 20 秒短快取。 |
| **零登入紀錄與空白密碼保護** | 後台登入頁不顯示歷史帳號清單，所有帳密欄採 `readonly` 解鎖鎖定＋隨機 `name`＋遮罩防瀏覽器自動填入；**管理員登入狀態不寫入 `localStorage`／`sessionStorage`**，重新整理或重開瀏覽器皆須重新手動輸入帳密；後台所有帳密管理頁的密碼欄一律預設空白（留空＝維持原密碼）。 |
| **全系統放大字體與即時縮放** | 首頁提供 `🔤 字體大小` 切換列（`小 16px` / `標準 18px` / `大 20px` / `特大 22px`），成績查詢頁頂部亦附快捷循環鈕，設定自動記憶並跨頁套用。 |
| **跨場次共用 NFC 晶片** | 晶片僅寫入 `姓名\|身份證字號`（約 20 bytes），不含活動代碼或參賽編號。發卡一次即可重複參加多場不同賽事與組別，感應時依鎖定活動自動比對資格。 |
| **一般距離賽 / 繞圈計時賽** | 1. **🏃 一般距離賽**（42K / 50K / 100K 等）：依完賽時間排名，支援分段時間、配速與 ETA。<br>2. **🔁 繞圈計時賽**（6H / 12H / 24H）：依單圈公里數累積圈數與總里程排名，逾時圈次留存紀錄但不計入正式成績；公開端即時里程精簡版隱藏身分證號與報到時間。 |
| **統一整數秒時間格式** | 全系統所有畫面、排行榜、分段明細、個人卡片、官方／客製化證書、Excel、DUV 匯出與雲端表單，**秒數一律採整數 `HH:mm:ss`（不含小數點）**。 |
| **統一律定起跑與現場報到** | 後台可一鍵立即鳴槍或指定 `HH:mm:ss` 套用全組，亦可單組微調。賽前由報到組（`checkin01`）感應 `CHECKIN`，**報到紀錄絕不計入圈數或賽道成績**。 |
| **多管理者獨立活動隔離** | 每位活動承辦人登入後**僅檢視與操作本人建立之活動、結案匯出、證書與名下作業員**；**最高管理員**另享有「👥 帳號管理專區」、「📜 歷年活動成績匯入」與「💾 資料庫備份還原與重置」完整權限。 |
| **已結束活動鎖定與結案專區** | 活動狀態改為「**已結束**」即鎖定防誤改，自動從進行中選單與即時賽事隱藏；並開放於後台「**專區 2：📦 已結案專區**」與成績查詢「**📜 歷年成績**」、「**🏅 證書列印**」。 |
| **刪除活動連動清理** | 刪除活動時同步永久清除本機與雲端該活動之報名明細（`Registrations`）與感應紀錄（`Scans`），共用晶片主檔（`Chips`）保留不受影響。 |
| **歷年匯入審查與 ⚔️ 八百壯士** | 上傳或貼上歷年成績後**先顯示預覽場次與明細供審查，確認後才寫入資料庫**；活動名稱含「**八百壯士**」自動納入英雄榜，並支援「年度場次 → 該場次選手明細」兩層鑽取查詢。 |
| **🏅 DUV 官方成績匯出** | 限定已結束活動，一鍵匯出符合 **DUV** 送審格式（3 列活動表頭＋11 欄明細）之 `.xlsx`（堆疊／分組工作表）與 `.csv`（UTF-8 BOM）；自動拆姓／名並依台灣身份證第 2 碼推算性別。 |
| **🏅 完賽證書製作與客製化** | 僅限「已結束」與「歷年」活動。提供 **6 款官方格式風格 × 6 款配色主題**（中英文對照）、後台「上傳自訂底圖拖曳套印」，以及公開端「上傳自訂底圖＋個人照片（3 款相框、縮放、畫布拖曳）」；100% 離線輸出 PNG、單張 PDF 與批次多頁 PDF。 |
| **個資隱碼保護** | 成績查詢頁與隱碼 Excel 全面隱碼身份證（如 `A123****89`）並隱藏 `DOB`；查詢仍支援輸入完整身份證以 SHA-256 雜湊安全比對。 |

### 選手狀態自動流轉規則

| 狀態 | 判定條件 |
|---|---|
| **⏳ 未報到** | 尚未感應 `CHECKIN` 報到晶片，且無任何賽道感應紀錄 |
| **✅ 已報到** | 已完成 `CHECKIN` 報到感應，等待到達統一律定起跑時間 |
| **🏃 賽道上** | 已報到且已達起跑時間，或已通過任一中途站／繞圈感應 |
| **🏁 已完賽** | 距離賽通過終點衝線門（`FINISH`）；繞圈賽達限時截止且有有效圈數 |

## 三、從零開始建置與版本升級步驟（約 10 分鐘完成）

### 步驟 1：建立 Google 試算表與部署後端 API

1. 建立一份新的 **Google 試算表**（例如「TUR 路跑晶片計時資料庫」）。
2. 點選上方「**擴充功能**」→「**Apps Script**」，清空預設內容，將 `gas/Code.gs` 完整貼上並儲存。
3. 上方函式選單選 **`setupSheets`** → 按「**執行**」（首次需授權「進階 → 前往 → 允許」），自動建立 **8 張工作表**：
   - `GlobalConfig`、`AdminAccounts`、`Events`（15 欄）、`StaffAccounts`、`Chips`、`Registrations`（14 欄，含 DUV 欄位）、`Scans`、`HistoryResults`（17 欄）。
4. 點右上角「**部署**」→「**新增部署作業**」：
   - 類型：**網頁應用程式** ｜ 執行身分：**我** ｜ 誰可以存取：**所有人 (Anyone)**
   - 複製產生的部署網址（`https://script.google.com/macros/s/....../exec`）。

> **舊版升級提醒（升至 API v3.11 / 前端 v3.13.2）**：
> 1. 貼上最新 `gas/Code.gs` 後，請點「**部署 → 管理部署作業 → 鉛筆圖示 → 版本選『建立新版本』→ 部署**」（原網址不變），即可啟用 `lite` 極速登入、20 秒公開快取、全平台作業員管理與試算表帳密純文字格式。
> 2. 上傳新版前端至 GitHub 後，手機／電腦開啟頁面**連續重新整理 2 次**即可更新至 `v3.13.2`。

### 步驟 2：填入共用雲端網址

開啟 `js/config.js`，將部署網址填入 `DEFAULT_GAS_URL`：
```javascript
window.APP_CONFIG = {
  DEFAULT_GAS_URL: 'https://script.google.com/macros/s/貼上您的部署網址/exec',
  AUTO_SYNC_ON_START: true
};
```

### 步驟 3：上傳至 GitHub 並啟用 HTTPS（Web NFC 必備）

> Android Chrome 的 Web NFC API **強制要求 HTTPS**，直接雙擊本機檔案無法使用實體 NFC。

1. 在 GitHub 建立公開（Public）儲存庫，上傳整個專案（務必保留 `css/`、`js/`、`gas/` 子資料夾）。
2. 進入 **Settings → Pages**：Source 選 **Deploy from a branch**、Branch 選 `main`、資料夾選 `/ (root)` → 按 **Save**。
3. 啟用後即可透過 HTTPS 使用：
   - **系統主入口**：`https://<您的帳號>.github.io/<儲存庫名稱>/`
   - **成績查詢頁**：`https://<您的帳號>.github.io/<儲存庫名稱>/public.html`

## 四、四大入口與預設帳號密碼總表

> **安全提醒**：管理員登入畫面**不顯示歷史帳號、密碼預設空白、不保存登入紀錄**；正式賽事請務必於「👥 帳號管理專區」修改所有預設密碼。

| **🏆 成績查詢 / 證書列印** | 免登入 | 免密碼 | 查詢即時賽事、即時里程、歷年成績、八百壯士英雄榜，並印製已結束／歷年完賽證書 |

## 六、雲端資料庫同步：單機離線 ⇄ 雲端連線互動步驟

### 兩種工作模式比較

| 模式 | 資料存放位置 | 是否自動連雲端 | 適用情境 |
|---|---|---|---|
| **📴 單機離線模式** | 僅存於本機瀏覽器 IndexedDB | **不會**自動上傳或下載 | 山區完全無網路、單機練習測試、避免測試資料污染雲端 |
| **🌐 雲端連線模式** | 本機 IndexedDB ＋ Google 試算表雙向同步 | **會**（開啟、登入、切回視窗、恢復網路時自動背景同步） | 正式賽事多台手機、主控電腦與公開成績查詢即時共用資料 |

### 4 步驟互動操作流程

1. **步驟 1｜依現場環境選擇模式**
   - 單機練習或無網路環境 → 切至 **「📴 單機離線」**。
   - 多台裝置正式協作 → 貼上 GAS 部署網址 → 點 **「💾 儲存並測試」** → 確認切換為 **「🌐 雲端連線」**。
2. **步驟 2｜離線期間照常作業（安全暫存不遺失）**
   - 無論是主動切「單機離線」或賽中「突發斷網」，新增活動、匯入名單、寫卡與 NFC 感應皆完全不受影響。
   - 所有尚未上雲端的異動，都會安全記於本機，畫面右上角會累計顯示 **`☁️ 同步 (N)`**。
3. **步驟 3｜切回連線按「🔄 立即雙向同步」（離線與雲端交會點）**
   - 回到有網路環境後，切換至 **「🌐 雲端連線」** 並點 **「🔄 立即雙向同步」**（或點右上角 `☁️ 同步 (N)`）：
     - **先上傳**：將本機待同步異動安全推送至 Google 試算表（內建防重複機制）。
     - **再下載**：將雲端其他裝置的最新紀錄拉回本機，讓所有裝置 100% 一致。
4. **步驟 4｜進階單向同步工具（特殊情境使用）**
   - **⬇️ 僅拉取雲端**：新手機剛啟用，想直接把雲端最新全部資料抓回本機。
   - **📤 強制推送本機設定至雲端**（限最高管理員）：剛用 `.json` 備份檔完成本機還原後，想把還原後的活動與帳號設定整批覆蓋寫上雲端時使用。

## 八、Android 硬體事前設定與常見問題排錯

### 1. Android 手機事前設定清單

| 檢查項目 | 注意事項 |
|---|---|
| **支援瀏覽器** | Web NFC **僅支援 Android Google Chrome（v89 以上）**；不支援 iOS Safari、電腦瀏覽器，也**不可在 LINE / FB 內建瀏覽器開啟**。 |
| **建議 NFC 晶片** | 建議 **NTAG213 / 215 / 216** 抗金屬貼紙或手環；唯讀／MIFARE 卡改用「**🔗 綁定 UID**」。 |
| **手機設定** | 開啟 **NFC**、開啟「**自動設定日期與時間（網路校時）**」、延長螢幕休眠並外接行動電源。 |
| **安裝 PWA** | Chrome 選單點「**加到主畫面**」全螢幕運行。 |
| **防連點秒數** | 距離賽建議 `30 秒`；繞圈賽建議 `60～120 秒`。 |

### 2. 常見異常排錯速查表

| 狀況 / 錯誤訊息 | 原因 | 解決方法 |
|---|---|---|
| `NotAllowedError` | Chrome 未允許 NFC 權限或手機 NFC 未開 | 點網址列左側圖示 → 權限 → 允許「NFC 裝置」，並確認手機已開啟 NFC。 |
| `NotSupportedError` | 晶片為 MIFARE Classic 或唯讀卡 | 改點「**🔗 綁定 UID**」直接綁定，或更換 NTAG 晶片。 |
| `NetworkError` | 晶片移開太快或未對準天線 | 貼緊手機背面天線並**靜止 1～2 秒**，聽到成功音效再移開。 |
| 報名系統一鍵推送（GAS API）報「**管理員身分驗證失敗**」 | 1. 誤填報名系統帳密或作業員帳號<br>2. 試算表 `AdminAccounts` 與 `GlobalConfig` 密碼不一致<br>3. 密碼前後多餘空白、大小寫不同或純數字前導 `0` 被試算表吃掉<br>4. 貼錯 GAS 網址 | 1. 填寫**晶片系統**管理員帳密並先於晶片後台實測可登入<br>2. 直接核對 Google 試算表 `AdminAccounts` 工作表（確認 `enabled=1`）<br>3. 升級 `gas/Code.gs` 至 `v3.11`（已強制純文字格式）並確認 GAS 網址與 `js/config.js` 一致。 |
| 重新整理後台要重新登入 | 本系統啟用**管理員零登入紀錄保護** | 屬正常安全設計，防止外人藉登入紀錄直接進入後台；重新手動輸入帳密即可。 |
| 單機離線切回雲端後資料還沒同步 | 單機離線期間不會自動上傳 | 切回「**🌐 雲端連線**」後點一次「**🔄 立即雙向同步**」即可完成雙向對齊。 |
| 專區 1 找不到已結束活動／專區 2 看不到進行中活動 | 已結束活動鎖定歸檔防誤改 | 進行中活動請於專區 1 改為「已結束」才可在專區 2 匯出與發證；若要重開請至專區 1「🏟️ 活動」點「🔓 重新開啟」。 |
| 雲端歷年時間變成 1899 年日期或無法使用極速登入 | GAS 仍停留在舊版 | 貼上最新 `gas/Code.gs`（`v3.11`）並點「管理部署作業 → 建立新版本 → 部署」。 |
| 更新 GitHub 後手機仍是舊版 | Service Worker 尚留舊版快取 | 於手機 Chrome **連續重新整理 2 次**即可更新至 `v3.13.2`。 |

## 九、免硬體快速體驗方式（電腦／手機皆可）

1. 開啟 `index.html` → 體驗首頁四大圖示方格與下方 `🔤 字體大小` 即時切換。
2. 點「**🛡️ 後台管理**」→ 選「🛡️ 最高管理權責」手動輸入 `admin` / `admin1234` 登入（體驗秒驗進入與自動展開賽事作業專區）。
3. 點上方「**🗄️ 資料庫專區**」→ 建議先切「📴 單機離線」→ 展開「🧪 測試資料與重置」→ 點「**⚡ 載入全情境測試資料（5 場活動）**」。
4. 依序體驗最新功能：
   - **專區 3（👥 帳號管理專區）**：切換「最高管理員／活動承辦人／作業人員」體驗建立帳號與空白遮罩密碼重設。
   - **專區 5（🗄️ 資料庫專區）**：體驗兩步驟「⬇️ 下載完整備份 (.json)」與「合併／覆蓋還原」即時結果回報，以及 4 步驟離線／連線同步指南。
   - **專區 2（📦 已結案專區）＆ 成績查詢頁（`public.html`）**：體驗 DUV 匯出、八百壯士兩層場次鑽取，以及 **6 款格式 × 6 款主題**官方與客製化完賽證書。
   - **作業人員登錄與本場模擬刷卡**：點右上「**登出 / 換人**」→ 點「**📡 晶片作業**」登入任一組別 → 展開「🧪 模擬感應測試」體驗刷卡。
